# 大床房公寓 · 1:1 三维户型

一个单文件、可在浏览器中直接打开的**交互式 3D 户型复原**页面。按户型图标注毫米尺寸 1:1 建模，并按确认方案在大卧室内布置了 King 软包大床及配套家具。

## 在线预览

**https://fengdu2077.github.io/apartment-3d/**

无需安装任何环境，点开即可旋转、缩放、查看。

## 户型与尺寸

- 外墙净尺寸：**9197 × 4845 mm**，约 **33.6 ㎡**（室内净面积）
- 大卧房：**25.5 ㎡**
- 干区（洗漱）：4.83 ㎡
- 卫生间：3.20 ㎡
- 层高：2.8 m（常规取值），东向整面落地玻璃窗，西向入户门

### 布置的家具（大卧房）

- **King 软包大床**：外径 2180 × 2100 mm、床头高 980 mm，床头靠南墙；方格软包床头板、双枕、床品、床尾搭毯、原木底座
- 两侧原木床头柜 + 蘑菇台灯
- 床尾软包凳、北墙通顶衣柜、电视柜 + 壁挂电视
- 梳妆台（镜 + 圆凳）、窗边休闲椅 + 边几、落地绿植

## 交互说明

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移 |
| 滚轮 | 缩放 |
| 点击房间 | 高亮并显示房间信息卡 |
| 点击门 / 窗 | 开合动画 |

左侧面板可切换：

- **观察视角**：立体 / 俯视（剖墙看平面布局）/ 人视
- **显示图层**：尺寸标注、房间标签、顶面、布置家具、墙体半透明（俯视剖墙）
- **门窗**：全部打开 / 全部关闭 / 重置视角
- **房间列表**：点击快速定位到对应房间

## 技术栈

- 单个 `index.html`，所有样式与脚本内联，无构建步骤、无外部图片
- [Three.js r128](https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js)（jsDelivr，cdnjs 备用）
- 原生 JS，响应式布局，桌面与移动端均可使用

## 本地运行

直接用浏览器打开 `index.html` 即可；或将本目录用任意静态服务器托管：

```bash
# 任选其一
npx serve .
# 或
python -m http.server 8000
```

## 说明

- 家具为示意性 3D 复原，位置与净距按确认方案 1:1 布置（床尾主通道约 1.23–1.43 m，床两侧净距 ≥ 1 m）。
- 卫生间门扇原图未明确，按干湿分离常规补设。
